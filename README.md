# MangaLivre

> Free and open sharing of manga in Brazilian Portuguese.

[Read in Portuguese](#português) · [Leia em Português](#português)

MangaLivre is a collaborative repository dedicated to making manga available in image format (PNG or JPG) for public and free access. The goal is simple: to facilitate access to information and culture, without barriers, without costs, and without intermediaries.

All content is organized by folders, with chapters separated when necessary, and made available in Brazilian Portuguese.

## Objective

To share manga freely and for free, ensuring that anyone can access, read, and distribute the content without restrictions. This project is born from the belief that access to information and culture is a right, not a privilege.

## Repository Structure

Each manga must be organized in its own folder. If there are chapters, they must be subfolders inside the manga folder. Images must be separated by episodes.

```
mangalivre/
├── Manga Name/
│   ├── Chapter 01/
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   ├── 003.png
│   │   └── ...
│   ├── Chapter 02/
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   └── ...
│   └── ...
└── Another Manga/
    ├── Chapter 01/
    │   └── ...
    └── ...
```

### Organization Rules

- **Language:** All content must be in Brazilian Portuguese.
- **Format:** Only images in PNG or JPG format.
- **Naming:** Use clear and standardized names for folders and files. Example: `Chapter 01`, `001.jpg`, `002.jpg`.
- **Numbering:** Images must follow a sequential numerical order to facilitate reading.

## How to Contribute

Anyone can contribute to the project. The process is free and open.

1. Fork the repository.
2. Create a folder with the name of the manga you want to add.
3. Inside that folder, create subfolders for the chapters (if applicable).
4. Add the episode images inside the respective chapter folders.
5. Make sure the content is in Brazilian Portuguese and in PNG or JPG formats.
6. Open a Pull Request describing what was added.

You can feed the project as much as you want, as many times as you want, with as many manga as you wish. There is no limit to contributions.

### Review Process

Every Pull Request is analyzed and reviewed to prevent current manga and copyright infringement. Only manga with more than ten years since their creation are allowed.

### Backup

The entire project is backed up regularly to prevent future data loss. If necessary, backups ensure that the content remains available and secure.

## License and Use

This repository is a space for free sharing. All content made available here is the responsibility of whoever adds it. The project does not claim ownership of any work and has no commercial purpose.

The objective is exclusively access to information and culture, freely and accessibly for everyone.

## Support the Project

If you believe in free access to information and culture, contribute. Share. Distribute. Knowledge grows when it is shared.

To support, just follow the steps in the **How to Contribute** section and open your Pull Request. Every contribution is welcome.

## Português

> Compartilhamento livre e gratuito de mangás em português brasileiro.

[Read in English](#mangalivre) · [Leia em Inglês](#mangalivre)

MangaLivre é um repositório colaborativo dedicado a disponibilizar mangás em formato de imagem (PNG ou JPG) para acesso público e gratuito. O objetivo é simples: facilitar o acesso à informação e à cultura, sem barreiras, sem custos e sem intermediários.

Todo o conteúdo é organizado por pastas, com capítulos separados quando necessário, e disponibilizado em português brasileiro.

### Objetivo

Compartilhar mangás de forma livre e gratuita, garantindo que qualquer pessoa possa acessar, ler e distribuir o conteúdo sem restrições. Este projeto nasce da crença de que o acesso à informação e à cultura é um direito, não um privilégio.

### Estrutura do Repositório

Cada mangá deve ser organizado em sua própria pasta. Se houver capítulos, eles devem ser subpastas dentro da pasta do mangá. As imagens devem estar separadas por episódios.

```
mangalivre/
├── Nome do Mangá/
│   ├── Capítulo 01/
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   ├── 003.png
│   │   └── ...
│   ├── Capítulo 02/
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   └── ...
│   └── ...
└── Outro Mangá/
    ├── Capítulo 01/
    │   └── ...
    └── ...
```

#### Regras de organização

- **Idioma:** Todo o conteúdo deve estar em português brasileiro.
- **Formato:** Apenas imagens nos formatos PNG ou JPG.
- **Nomenclatura:** Use nomes claros e padronizados para pastas e arquivos. Exemplo: `Capítulo 01`, `001.jpg`, `002.jpg`.
- **Numeração:** As imagens devem seguir uma ordem numérica sequencial para facilitar a leitura.

### Como Contribuir

Qualquer pessoa pode contribuir com o projeto. O processo é livre e aberto.

1. Faça um fork do repositório.
2. Crie uma pasta com o nome do mangá que deseja adicionar.
3. Dentro dessa pasta, crie subpastas para os capítulos (se aplicável).
4. Adicione as imagens dos episódios dentro das respectivas pastas de capítulo.
5. Certifique-se de que o conteúdo está em português brasileiro e nos formatos PNG ou JPG.
6. Abra um Pull Request descrevendo o que foi adicionado.

Você pode alimentar o projeto à vontade, quantas vezes quiser, com quantos mangás desejar. Não há limite de contribuições.

#### Processo de Revisão

Todo Pull Request é analisado e revisado para evitar mangás atuais e quebras de direitos autorais. São permitidos apenas mangás com mais de dez anos de criação.

#### Backup

Todo o projeto é submetido a backups regulares para evitar quedas futuras ou perda de dados. Se necessário, os backups garantem que o conteúdo permaneça disponível e seguro.

### Licença e Uso

O objetivo é exclusivamente o acesso à informação e à cultura, de forma gratuita e acessível para todos.
